# Pruthvi Nag Gattu - Healthcare Data Engineering Portfolio

Live Web Platform: [https://pruthvi51.github.io](https://pruthvi51.github.io)

This repository hosts the static single-page portfolio showcasing open-source distributed healthcare data engineering systems, technical papers, and benchmark metrics.

## Portfolio Projects
- **CareLake:** Governed Medallion Lakehouse on Apache Iceberg, PySpark Bronze Ingestion, and dbt.
- **TenantFlow:** Multi-Tenant Healthcare Data Orchestration Platform with PySpark AQE and Airflow.
- **ReconX:** Cross-Database Data Reconciliation and Table-Diff Framework (5 SQL Dialects, PySpark).
- **SQLSage:** Autonomous Enterprise NL-to-SQL Translation with Schema-Guided Constrained Decoding.
- **DocForge:** Clinical Document Intelligence Pipeline Converting EHR Notes to FHIR R4 and OMOP CDM.
